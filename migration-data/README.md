## 2026-08-15 완료된 것 (Claude 자체 판단으로 추가 고도화)

- **예방정비 임박 TM 위젯 (예지보전)** — "TM-CBM"(Condition-Based Maintenance)의 핵심 취지에
  맞춰, 과거 이력 기반 반응형 등급 표시에서 나아가 앞으로의 정비 시점을 예측하는 기능 추가.
  운영중 TM 중 MTBF 계산이 가능한(고장성 교체 2회 이상) 것들에 대해 `최근 고장일 + MTBF`로
  예상 다음 정비 시점을 산출하고, 오늘 기준 이미 지났거나 90일 이내로 임박한 TM을 경과/임박
  순으로 리스트업. 시리얼/편성·위치/최근 고장일/MTBF/예상시점/경과·임박 배지 표시, 클릭 시
  TM 리포트로 이동. 위젯 커스터마이징 목록에도 추가됨. 실데이터 2건(경과 상태) 확인.

  있어?"). 브라우저로 두 시나리오 모두 실제 응답 확인 완료.
