## 내일 할 일 (우선순위 순, 전부 크레딧 필요)

### 1. 챗봇 인사말 버그
"안녕"처럼 도메인 질문이 아닌 간단한 인사에 "질문을 이해하지 못했어요"라고 잘못 응답함.
```
챗봇에 "안녕"이라고만 인사하면 "죄송해요, 질문을 이해하지 못했어요"라고 나와.
도메인 질문이 아닌 간단한 인사말(안녕, 안녕하세요, hi 등)은 자연스럽게 인사로
받아주고, 뭘 도와줄 수 있는지 안내하도록 고쳐줘. 브라우저로 직접 "안녕" 쳐보고
정상 응답 나오는지 확인해줘.
```

### 2. 구글시트 연동 (원본 엑셀 ↔ DB 양방향 동기화) — 새 요구사항, 아직 설계 전
사용자가 "파일도 쓰고 홈페이지도 써야 의미있다"며 원본 엑셀과 Lovable DB의
자동 동기화를 요청함. 결론:
- **다른 사람이 홈페이지에서 입력한 게 다른 사람 화면에도 반영되는 건 이미 됨**
  (Supabase 공용 DB 구조라 원래 그렇게 동작 — 구글시트 연동과 무관).
- 구글시트 연동은 **"DB 변경사항을 원본 엑셀(구글시트)에도 반영"하는 별도 기능**.
- 진짜 실시간 자동 반영은 어려우니 "동기화 버튼" 또는 "주기적 자동 동기화"로
  시작하는 걸 추천함.
- **사용자가 먼저 해야 할 것**: (1) https://lovable.dev/dashboard?connectors 에서
  Google Sheets 커넥터를 본인 구글 계정으로 연결, (2) 원본 `.xlsx`를 구글드라이브에
  올려서 구글시트로 변환(또는 새 구글시트에 데이터 옮기기).
- 커넥터 연결 완료됐다는 확인 받으면, Lovable 에이전트에게 동기화 로직 구현 요청.
