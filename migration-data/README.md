## 1. "안녕" 인사말을 여전히 못 알아들음
전에 GREETING_RE / greetingAnswer()로 고쳤었는데 실제로 다시 테스트해보니 안 먹힘. 어디서 막히는지 원인 찾아서 확실히 고쳐줘. (혹시 그 사이 detectRepairIntent 정규식이 확장되면서 "안녕" 같은 짧은 문장이 다른 분기에 먼저 걸리는 건 아닌지 확인)

## 2. "조회"만 입력하면 이상한 답변
"조회"처럼 목적어 없는 단어만 오면 엉뚱한 답 대신 "무엇을 조회해드릴까요? (예: 111편성 상태, 시리얼 조회, 최근 고장이력 등)"처럼 되물어야 함.

## 3. 존재하지 않는 편성 질문 시 안내 부족
"101편성 TM상태"처럼 존재하지 않는 편성(우리 데이터는 111~116만 있음)을 물으면 그냥 "이해 못했어요"가 아니라 "101편성은 없어요. 현재 111~116편성만 있습니다."처럼 구체적으로 안내해야 함.

## 4. "111편성 TM상태" 응답이 이력 나열만 하고 요약이 없음
지금은 이력을 쭉 나열하는 것 같은데, 그러지 말고 챗봇 화면에서 한눈에 이해되는 요약으로 바꿔줘. 예: "111편성 24대 중 긴급 2대, 주의 3대, 관찰 1대, 정상 18대입니다. 긴급: 1711호차 1TM(88091-XX), 1811호차 2TM(...)" 처럼 등급별 집계 + 긴급/주의 등급만 구체적으로 짚어주는 식.
