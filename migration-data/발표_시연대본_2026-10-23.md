# TM-CBM 발표 시연 대본 (약 5분)

주소: https://tm-cbm.lovable.app · 휴대폰으로 시연 (PC 화면은 대시보드·장치 확장만)
숫자는 2026-10-23 앱 기준입니다. 발표 직전에 한 번 열어 숫자를 확인하세요.

---

## 0. 첫 문장 (10초)

> "지축 시스템이 **고장 난 뒤**를 잘 정리한다면, 저희는 **고장 나기 전**을 봅니다.
> 상태를 재고, 표준으로 판정하고, 근거별로 수명을 예측하고, 말로 시키면 챗봇이 다 합니다."

포인트: **등급은 사람이 아니라 EN 50126 매트릭스가 5년 고장 기록으로 자동 판정**.

| 누를 곳 | 말할 것 |
|---|---|
| 점검 입력 창에서 절연저항 **3** 입력 | "기준 5㏁ 밑이면 칸이 바로 빨개집니다. 기준은 **표준작업절차서 9·19쪽 원문** 그대로." |

| 취소 → '상태 점검' 화면 '이번 주 점검 계획' | "사람이 고르지 않습니다. 등급·지난 점검·기준 밖 값·수명 예측·반복 고장 자리를 점수로 합쳐 평일 5일 일정을 짜고, 같은 날은 같은 편성끼리 묶습니다." |

주의: 저장은 담당자 비밀번호가 필요합니다. 시연 중에는 **저장하지 말고 취소**하세요 (실제 기록이 남습니다).

## 5. 챗봇 — 시키면 다 한다 (60초) ★ 강점

아래를 순서대로 입력 (복사해 두기):

1. `오늘 뭐부터 점검해야 돼?` → 긴급 TM + 마지막 점검일
2. `88091-48 절연저항 120 브러시 33 이음 없음` → 점검 기록 초안, '저장' 직전까지 (→ **취소**)
3. `88091-48 언제 바꿔야 돼` → 등급 + 수명 근거
4. `차륜 수명 예측이랑 뭐가 달라` → 비교 설명
5. `88091-48 AI 소견` → ■ 상태 요약 / 판정 근거 / 권고 조치 / 추적 항목
6. `이번 달 요약 만들어 줘` → 표로 정리된 월간 보고
7. `다음주 점검 일정` → 날짜별 편성·TM·이유

말할 것: "현황·등급·이력 답은 AI 없이 **규칙으로 계산**합니다 — 같은 질문엔 늘 같은 답. AI는 문서 검색·음성·고장분류·사진·소견 다섯 곳에만 씁니다. 지어낸 숫자가 들어올 길이 없습니다."

AI가 느리거나 끊겨도: 소견은 **앱 규칙으로 자동 정리**되어 나옵니다 (화면에 그렇게 표시됨).

## 지축 대비 한눈에

| | 지축 (검수도 AI로) | TM-CBM |
|---|---|---|
| 기본 데이터 | 고장 이력(사후) | 고장 이력 **+ 상태 점검값(사전)** |
| 판정 | 이력 분석 | **EN 50126 매트릭스 자동 등급** + 문서 원문 기준 |
| 수명 예측 | 차륜 지름 한 치수 | **세 근거**(고장 간격·브러시 마모·절연 저하) + 신뢰도 |
| 위치 원인 | — | **반복 고장 '자리'** 감지 → 차량 측 점검 안내 |
| 예비품 | 재고 수량 | **교체 속도로 남은 개월** |
| 점검 계획 | — | **이번 주 일정 자동 편성 + QR 현장 기록지** |
| 사용 방식 | 화면 조회 | 화면 + **챗봇(말로 기록·조회·소견·보고)** |
| 확장 | 통합(여러 장치 화면) | **같은 6층 구조, 장치 설정만 교체** |

(지축 쪽은 발표 사진 기준으로 적었습니다. 확인 안 된 부분은 말로 비교하지 마세요.)

## 예상 질문과 답

- **"점검값은 실제로 잰 건가요?"** → "TM별 초기 점검값을 넣어 두고 시작했습니다. 앞으로 현장 점검값이 쌓이면 추세와 수명 예측이 그대로 계산됩니다." (실측 결과라고 하지 마세요.)
- **"예측이 맞는다는 근거는?"** → "근거별 계산식과 원 데이터를 화면에 그대로 보여 줍니다. 근거가 없으면 '산출 불가'로 둡니다. 과거 이력으로 등급 적중률도 따로 시험했습니다(대시보드 분석 탭 → 위젯 선택에서 '등급 적중률(참고용)' 켜기)."
- **"AI가 틀리면?"** → "판정과 숫자는 AI가 아니라 규칙이 냅니다. AI는 설명·분류 추천·사진 소견만 하고, 사람이 확인 후 저장합니다."
- **"다른 장치에 쓰려면 얼마나 걸려요?"** → "장치 템플릿(항목·기준값·문서)만 채우면 같은 화면이 동작합니다. 자료와 문서가 관건입니다."
- **"현장에서 쓰기 어렵지 않나요?"** → "휴대폰 아래 탭 6개, 점검 입력은 숫자 네 칸 + 사진 한 장. 말로 해도 됩니다."
